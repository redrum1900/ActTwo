# 地点与 NPC 位置方案

本文件记录 2026-10-01 与作者确认并实现的方向。具体配置参见 [苏念剧本配置入门](苏念剧本配置入门.md)。

- 剧本中的「电脑上」是一个地点，与「饭店」「苏念家中」同属地点列表；它不等于玩家家，也不额外表示苏念的物理位置。
- 每个 NPC 同一时间只有一个当前地点。NPC 配置提供初始地点；开局后，存档保存当前地点，规则效果可以移动 NPC。
- 苏念开局在「电脑上」。规则将她移动到「饭店」后，她不再出现在「电脑上」。若玩家正在与她对话，聊天关闭并提示 NPC 已离开。
- 剧本级 `locations.json` 统一配置地点资料、玩家可见条件 `visibleWhen`、当前进入条件 `enterWhen`、互动方式、调查点和物品；不再有单独的 `placements.json`。NPC 可以先移动到玩家尚未解锁的地点。
- 剧本各 JSON 是规则与初始值的定义；发布版本的原始 JSON 不随游玩改变。另可有**可变的运行时剧本快照**，记录基于当前存档计算出的可见／可进入地点等查询结果。它是缓存或投影，不是第二份规则，也不替代存档中的事实。角色快照同理由定义与存档状态计算。
- 当前加载器每次请求仍会重读 JSON；存档绑定版本和内容哈希，内容变化后旧档会被拒绝。`unlockedLocations` 是永久解锁记录，只增不减，不等同于可能随条件变化的「当前可进入地点」。
- 运行时剧本快照也可包含结局／成就的当前查询结果（条件目前是否满足、是否已经获得、玩家可见的名称与说明）。定义和条件仍来自原始 JSON；「已经获得」是永久记录，不能只靠当前条件反推。图鉴获得应在状态结算时持久化，再生成查询快照。

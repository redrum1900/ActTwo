# AI 运行与实验记录

本页保留早期调试信息，不是创作者配置指南。项目入口和日常创作方法见 [README](../README.md)。以下费用均是按当时渠道价格估算，不能代表当前报价。

## 对话模式

默认 `AI_CHAT_MODE=settled`：先做语义判断、预结算，再生成最终回复。试验性的 `AI_CHAT_MODE=combined` 让模型在一次请求中同时返回台词与建议规则 ID；后端仍复核条件、结算并保存。单请求模式不自动补发付费修复请求，也不会把格式错误的普通文本当作“无事件”。这类响应的稳定性仍需以真实渠道验证。

单请求模式的早期长档试验使用 82 条消息、约 13,103 字符，三次请求中一次有效、两次格式校验失败，未修改正式存档。对应日志在本地 `data/ai-combined-probe.jsonl`；当时估算费用依次为 $0.009728、$0.004205、$0.003763。失败请求仍会产生费用。早期两步模式的两轮独立实测，每轮两次调用且无重写，估算分别为 $0.004339、$0.004196；渠道返回的输入 token 与本地判断请求长度差异较大，原因尚未核实。这些样本不足以证明某种模式更便宜或更稳。

固定前缀试验使用 `createCombinedChatAdapter({ promptLayout: 'fixed-prefix', ... })`，把世界背景、通用人格和无门槛语义规则放入固定系统消息；有条件保护的内容仍按当前状态筛选。该选项没有接入默认服务流程。四次对照的本地日志为 `data/prefix-1790859022641.jsonl` 及同名前缀报告；旧布局第二次输入 17,387 token、缓存命中 16,896、输出 388，估算 $0.004354；固定布局第二次输入 17,496、缓存命中 16,896、输出 7，估算 $0.003870，但格式失败，不能视为等质量省钱。

需要复现实验时可用 `npx tsx scripts/probe-prompt-layout.ts --live --game <故事 ID> --owner <账号 ID>`。这会产生四次付费请求；脚本只读 MySQL 自动档及其发布快照，报告与角色回复留在服务端本地。费用汇总可用 `npm run ai:cost`，或 `npm run ai:cost -- <日志路径>` 查看指定日志。缺失的上游用量保持未知，不当作免费。

## 记忆与失败处理

每个 NPC 独立保留聊天原文和结构化长期记忆，字段包括事实、关系、承诺、边界与未完话题。摘要带来源消息 ID；发给模型时使用正文，不发送来源 ID。记忆与未压缩原文超过阈值时会异步压缩较旧轮次，近期完整轮次保留；摘要失败或未覆盖的原文不会静默删除。

后台摘要只在存档 revision 与原状态仍匹配时写入。新游戏、读档或其他新操作会使旧任务失效；摘要更新不增加游戏 revision。服务器重启可能中断后台任务，但原始消息不丢，下次满足条件后可重试。记忆摘要本身也消耗模型额度，因此应按多轮平均费用评价，而不是只看触发压缩的第一轮。

玩家发言会先在界面出现，模型回复流式展示为临时文字；如结算后修订，最终内容可能替换临时稿。失败的本轮不结算、不保存，玩家可重试。开发环境可设置 `GAME_DEV_DEBUG=1`，用当前账号查看规则诊断；生产模式强制关闭该接口。

# ACT II 后续工作记录

以下事项由项目负责人提出。前后端业务目录拆分和 README 的 Web 操作说明已落地；完整示例验证与服务器部署仍属后续工作。

## 前后端架构与代码重构

- 已把公开故事目录与正式游玩路由从 API 入口拆出，并集中版本化存档会话；已把创作中心的草稿状态、登录视图和故事列表视图拆开。
- 前端玩家入口已按 `app/`、`catalog/`、`story-detail/`、`gameplay/`、`usage/` 和 `shared/` 归位；创作中心内部进一步按入口、表单、会话、模型、工作流及客户端归类。后端账号、创作、试玩及 MySQL 实现已分别归入 `modules/auth/`、`modules/creator/`、`modules/playtest/` 和 `infrastructure/mysql/`。
- AI 服务适配、流解析、审计与成本汇总已归入 `infrastructure/ai/`，用量查询接口归入 `modules/usage/`；对话、记忆和开局表单归入 `modules/gameplay/`，试玩快照会话归入 `modules/playtest/`。旧测试存档适配器已移除，正式持久化和集成测试统一使用 MySQL；共享剧本仓库仍保留纯脚本测试入口。任何后续迁移均保持对外 API、数据库、已发布故事及存档兼容，除非另行确认改变。
- 本地设计和计划放在已忽略的 `docs/superpowers/` 中，不上传 Git。

## 创作者使用文档

- README 已以 **Web 创作中心的操作流程**为主线，说明从新建故事、配置、保存、校验、试玩到提交审核；内部 JSON 只作为高级视图提及，模型实验记录移至独立文档。
- 「雨夜来信」最小示例已按当前空白故事结构通过配置校验，尚未在浏览器中完成实际试玩验收；逐项默认值与边界约束可在后续独立手册中继续细化。

## 服务器部署

- 已采用单 Node 进程同时提供前端与 API、宝塔 Nginx 反向代理、独立 MySQL 的部署方案；模板和操作清单见 `docs/deployment.md` 与 `deploy/`。
- 应用服务器已提供 IP 与宝塔信息；SSH 账号/端口、服务器操作系统、域名及实际安装路径仍待核对。模板尚未在该服务器执行或验收。
- 公网开放前仍需补齐登录/注册与导入的限流或并发保护，以及可监控的健康检查。

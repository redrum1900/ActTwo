# 移除道具标签并以剧情事件表达剧情事实

## 目标

道具只负责定义物品及其当前归属；物品发生可见、实质变化时，作者可创建另一件道具并用规则替换。跨对话持续成立的剧情事实（例如「苏念同意阅读训练笔记」）由现有剧情事件定义、规则效果和剧本快照表达。创作中心不再展示没有清晰用途的道具初始标签。

## 范围与边界

- 完全移除**道具标签**：`ItemDefinition.initialTags/hiddenTags`、`ItemRuntime.tags`、`Condition.hasItem.tags`、`addItemTag/removeItemTag`，以及背包、AI 道具摘要和创作中心的道具标签输入。
- 保留 `hasItem` 对道具 ID 和持有者的判断；保留道具 `variants`，其条件可引用剧情事件。
- 保留玩家/NPC 的标签、标签型指标及其规则效果。它们不是道具标签，不在本次迁移范围。
- 不改变剧情事件的现有格式：`manifest.json.storyEvents` 定义 `{id,label,detail}`；规则使用 `recordStoryEvent`；条件使用 `storyEvent`；快照 `storyEventFlags` 保存已发生事件。
- 先前已明确旧存档无需兼容；此处不做旧存档字段迁移。现存作者草稿不自动删除未知字段；发布校验应对已废弃的道具标签字段或效果给出可定位错误，作者可在 JSON 模式修正。

## 示例剧本迁移

1. 在苏念剧本的 `storyEvents` 增加 UUID 定义「获准阅读训练笔记」。
2. `read-practice-note` 规则保持“玩家持有训练笔记”的前置条件，效果改为记录该剧情事件。一次性规则避免重复触发；剧情事件本身也去重。
3. `understand-practice-note`、相关人物表现和训练笔记的详情变体，改以该剧情事件判断。需要道具仍在玩家手中时，同时组合 `hasItem`。
4. 旧照片的「共同回忆」标签没有被后续条件引用，删除该效果；它的叙述和好感效果保留。
5. 删除样本道具的初始标签。其他道具名称、描述、归属、发现与获取流程不变。

## 运行流程

玩家持有训练笔记 → 与苏念对话符合 `read-practice-note` 语义规则 → 规则结算成功并记录「获准阅读训练笔记」事件 → 剧本快照持久化 → 后续人物表现、规则和道具详情按 `storyEvent` 判断。没有触发规则时，单纯持有笔记不会得到阅读许可；单纯说过相关话题也不会绕过规则结算写入事件。

## 错误与验证

- 无效或已删除的剧情事件引用继续由现有剧本校验拦截，指出配置路径。
- 已废弃的道具标签字段、`hasItem.tags` 和道具标签效果不能默默失效；发布校验报告确切路径和替代建议。
- 条件编辑器仍提供“持有道具”并只选择道具与持有者。事件通过独立“剧情事件”条件选择。
- 存档运行时不再初始化或修改物品标签；玩家背包和 AI 摘要不再发送标签。

## 验收

- 新游戏、对话与存档加载中，记录的剧情事件能使训练笔记详情和苏念人物表现跨对话切换。
- 未获许可时分支不提前出现；规则结算失败时不写事件。
- 原有道具获取、转移、展示和图片不受影响；玩家/NPC 标签型指标仍工作。
- 创作中心道具页、合同、运行时视图都不再含道具标签；旧式道具标签配置无法通过发布校验。
- 相关单测、集成测试、全量测试和构建通过。
